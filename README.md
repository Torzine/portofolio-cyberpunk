# 🌐 Mini Project: Responsive Personal Portfolio

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![Responsive](https://img.shields.io/badge/Responsive-Design-success?style=for-the-badge&logo=responsive-design&logoColor=white)]()

Sebuah halaman website **Portofolio Pribadi** yang dirancang sepenuhnya responsif menggunakan kombinasi HTML5, CSS3 murni, Flexbox, dan Media Query tanpa bantuan framework eksternal. Project ini dibuat untuk memenuhi tugas mata kuliah **Pemrograman Web I** di **Universitas Surakarta**.

> "Passionate about crafting clean, responsive web experiences. When I'm not pushing code, I'm in the pool or mid-game. Currently leveling up my front-end skills — one pixel at a time."

---

## ✨ Fitur & Struktur Halaman
Sesuai dengan ketentuan tugas, website ini dibangun dengan struktur layout yang lengkap:
* **Header & Navigation Menu:** Navigasi horizontal di desktop dan adaptif di perangkat mobile.
* **Hero Section:** Pengenalan singkat dengan tipografi yang modern dan estetik.
* **Main Content (Gallery/Card):** Menampilkan grid project interaktif yang fleksibel di berbagai ukuran layar.
* **Footer:** Catatan hak cipta akademis yang rapi.

---

## 🎨 Desain & Tipografi

### Font Family
Project ini menggunakan dua tipe font dari Google Fonts untuk menciptakan estetika yang modern, bersih, dan sedikit sentuhan *tech-forward*:

* **Orbitron** — Font utama untuk Headings (h1, h2, h3)
    * Memiliki karakteristik geometris sans-serif dengan impresi futuristik. Sangat cocok untuk judul besar dan elemen penegas.
* **Share Tech Mono** — Font sekunder untuk elemen teks dan konten teknis
    * Font monospace berjarak tetap (fixed-width) yang memberikan kesan rapi, profesional, layaknya sebuah *code environment*.

### Palet Warna
* `#2c3e50` (Dark Slate / Charcoal) — Warna utama untuk Header & Footer memberikan kesan kokoh.
* `#3498db` (Indigo/Blue Accent) — Warna aksen modern untuk gradasi Hero Section.
* `#f4f7f6` (Off-White) — Warna latar belakang yang bersih dan nyaman di mata.

## 📱 Responsivitas (Media Queries)
Layout website secara cerdas berubah menyesuaikan resolusi perangkat pengguna:

| Perangkat | Resolusi Lebar | Karakteristik Layout |
| :--- | :--- | :--- |
| **Desktop** | `> 968px` | Layout horizontal, menu sejajar kanan-kiri, Card project tersusun 3 kolom. |
| **Tablet** | `577px - 968px` | Layout mulai fleksibel (fluid), ukuran font menyesuaikan, Card berubah menjadi 2 kolom. |
| **Mobile** | `<= 576px` | Layout berubah total menjadi vertikal. Menu navigasi menumpuk rapi ke bawah, ukuran gambar proporsional. |
